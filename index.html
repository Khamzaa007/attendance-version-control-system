GIT REPO V 3.0

GitHub-қа кодты жүктеу және орналастыру қадамдары

Әзірленген прототипті GitHub репозиторийіне жіберу және версияларды басқару үшін төмендегі командалар қолданылды:

1. Репозиторийді іске қосу

Локалды папкада Git ортасын орнату.

git init

2. Файлдарды қосу

index.html және басқа файлдарды индекске қосу.

git add .

3. Commit жасау

Өзгерістерді түсіндірме жазбамен сақтау.

git commit -m "v3.0 native prototype"
